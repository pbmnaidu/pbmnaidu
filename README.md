## Featured Project

### [DSA⁴⁰⁴](https://dsa404.vercel.app)

A structured DSA preparation platform designed to make daily practice, revision, progress tracking, contests, and coding guidance more consistent.

**Highlights**

- Structured daily workspace with curated DSA problem sheets
- Adaptive planning with spaced repetition and revision workflows
- Progress analytics, topic roadmaps, solved-problem archives, and contest tracking
- Coding guidance with notes, complexity references, and optional GitHub synchronization
- Multi-platform coding profile and contest integration support

**Built with:** Next.js · React · TypeScript · Tailwind CSS · Firebase · Cloud Firestore
